# Public Sans

Variable weight font used by Bugbound, self-hosted to avoid a runtime font service.

- Source: https://github.com/google/fonts/tree/main/ofl/publicsans
- Download: https://raw.githubusercontent.com/google/fonts/main/ofl/publicsans/PublicSans%5Bwght%5D.ttf
- Retrieved: 2026-09-05
- License: SIL Open Font License 1.1, included in `OFL-PublicSans.txt`.

The downloaded font is unmodified; only its filename is shortened.
